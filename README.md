## <img src="https://raw.githubusercontent.com/aequiarch-org/aequiarch-esports/main/.github/icons/setup.png" alt="Setup" width="24" height="24"> Getting Started

<div align="center">

### Prerequisites

- ✅ Node.js 18+
- ✅ pnpm 8+
- ✅ Supabase Project
- ✅ Stripe Account

### Installation

```bash
# Clone the repository
git clone https://github.com/aequiarch-org/aequiarch-esports.git
cd aequiarch-esports

# Install dependencies
pnpm install

# Copy environment variables
cp .env.example apps/web/.env.local

# Set up database
pnpm db:migrate
pnpm db:seed

# Start development server
pnpm dev

# Open http://localhost:3000
```

## <img src="https://raw.githubusercontent.com/aequiarch-org/aequiarch-esports/main/.github/icons/usage.png" alt="Usage" width="24" height="24"> Usage Examples

### Create a Tournament

```typescript
import { createTournament } from '@/lib/tournament';

const tournament = await createTournament({
  name: 'Winter Championship',
  game: 'Valorant',
  startDate: '2026-12-15',
  endDate: '2026-12-31',
  entryFee: 15,
  maxTeams: 32,
  format: 'double_elimination',
});
```

### Join a Tournament

```typescript
import { joinTournament } from '@/lib/tournament';

const result = await joinTournament({
  tournamentId: 'tournament-123',
  teamId: 'team-456',
});

console.log('Joined tournament:', result);
```

### Submit Match Result

```typescript
import { submitMatchResult } from '@/lib/match';

await submitMatchResult({
  tournamentId: 'tournament-123',
  matchId: 'match-789',
  winnerId: 'team-456',
  score: '2-1',
  round: 3,
});
```

### Get Leaderboard

```typescript
import { getLeaderboard } from '@/lib/leaderboard';

const leaderboard = await getLeaderboard({
  game: 'CS2',
  limit: 100,
  region: 'north_america',
});

console.log('Top 100 teams:', leaderboard);
```
